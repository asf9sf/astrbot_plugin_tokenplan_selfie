# TokenPlan 角色自拍插件（AstrBot）

让 AI 以自己的人格身份拍照——自拍、风景、随手拍。核心是**锁脸**：认定一张脸之后，换衣服换场景都还是同一个人。

## 长相从哪来：人设 → 外貌提示词

角色长什么样不是写死的，而是**由当前人格设定推理出来的**：

```
用户在人格里写好人设（发色、年龄、气质…）
        ↓
第一次 /自拍 时，插件把人格文本交给大模型
        ↓
大模型输出一段 40-80 字的纯外貌描述（只写长相，不写性格/衣服/场景）
        ↓
存进 face/appearance.txt，之后每张图都复用它
```

这样做的好处是：换人格就换长相，不用手动改提示词；而且**只总结一次**，后面所有图共用同一段描述，不会因为每次重新描述而漂移。

- `/外貌` —— 看看当前这段描述长什么样
- `/外貌重写` —— 丢掉旧的，按当前人设重新总结一份

> 首次发 `/自拍` 时如果插件还没读过人格（比如刚启动、还没聊过天），会提示你「先随便聊一句」。因为人格文本是每轮对话时顺带缓存下来的，纯命令不会触发。

## 锁脸流程（重要）

有三种定脸方式，**推荐直接用你手上的图**，比抽卡靠谱得多：

**方式一：直接对 AI 说话（最省事）**

```
[发一张图] 就用这张脸
[发一张图] 记住我长这样
[发一张图] 以后都按这张
```

AI 会自己判断这是确认意图，调用 `lock_face` 把图锁成角色的脸。**需要先在人格里勾选 `lock_face` 工具。**

用户只是发图聊天、让你评价照片时，AI 不会误锁。

**方式二：命令**

```
[发一张图] + /定脸
```

插件直接抓取这条消息里的图片存成角色的脸。

**方式三：从生成的候选里挑**

```
/自拍           → 生成 4 张候选，按顺序编号 1~4
/定脸 2         → 把第 2 张锁成角色的脸
```

**辅助命令**

```
/定脸状态       → 查看当前锁定信息
/定脸重置       → 解除锁定，重新挑
```

锁定后的图片和元数据存在插件数据目录：

```
data/plugin_data/astrbot_plugin_tokenplan_selfie/face/
├── locked.png       # 锁定的参考图
├── face.json        # 锁定时间、外貌描述、来源
└── appearance.txt   # 由人设总结出的外貌描述（所有自拍共用）
```

## 让 AI 自己拍

开启 `enable_tool` 后，需要在**人格管理 → 工具**里勾选两个工具：

- `take_selfie(scene, outfit, mood)` —— 自拍，画面里有角色本人
- `take_photo(scene)` —— 风景/环境照，画面里没有人

勾选后，用户说「你在干嘛」「发张自拍」「你那边天气怎么样」之类的，AI 会自己决定拍一张。

## 模型怎么选（省钱）

百炼华北2（北京）公开按量价：

| 模型 | 价格 | 定位 |
| --- | --- | --- |
| `wan2.7-image` | **0.20 元/张** | 标准版，最便宜 |
| `wan2.7-image-pro` | 0.50 元/张 | 旗舰版，主体一致性、文字渲染更强 |
| `qwen-image-3.0-pro` | Pro 档，约 0.5 元/张 | 人物身份保持强，1~3 张参考图 |

**三者里 `wan2.7-image` 最便宜，另外两个大约是它的 2.5 倍。**

关键点：`wan2.7-image` 本身**也支持参考图**（`image` 字段可传 1 张或多张，URL 或 base64），所以锁脸不一定非要上贵模型。本插件默认两个都填 `wan2.7-image`：

- **没锁脸 / 拍风景 / 锁脸自拍** → 全部 `wan2.7-image`，0.2 元/张
- 如果实测发现换场景后脸漂移明显 → 把「带参考图模型」单独改成 `wan2.7-image-pro`，只让锁脸的自拍走贵模型

一次 `/自拍` 出 4 张候选 = 0.8 元。锁定后每张 0.2 元，改 pro 则 0.5 元。

### 换成百炼业务空间（用套餐以外的模型）

把「服务地址」改成业务空间地址即可，插件会自动识别协议：

| 填法 | 走的协议 |
| --- | --- |
| `https://token-plan.cn-beijing.maas.aliyuncs.com` | DashScope 原生接口（套餐默认） |
| `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com` | DashScope 原生接口 |
| `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | **OpenAI 兼容协议** `/images/generations` |

判定规则：**地址里带 `compatible-mode` 就走 OpenAI 协议，否则走原生接口。**

OpenAI 协议下图生图用 `image` 字段传参考图（数组），失败会自动回退到同一空间的原生接口。

改用业务空间后，API Key 要换成该空间的普通 Key（`sk-` 开头），不是套餐密钥（`sk-sp-` 开头）。

## 为什么图一看就是 AI 生成的

问题几乎不在人，在**背景**。

AI 画背景是「设计出来的」：白墙、一盆绿植、大面积柔焦，干净得像样板间。
真实背景是「被生活堆出来的」：插座、外卖盒、没叠的衣服、卷边的贴纸、地上的拖鞋。

所以插件里维护了四个池子，由「**背景环境真实感**」这一档统一控制：

| 池子 | 条数 | 作用 |
| --- | --- | --- |
| 真实生活空间 | 10 | 出租屋床边、老旧厨房、沙发一角、宿舍上床下桌、便利店货架…… |
| 生活痕迹 | 5 | 杂物没收、墙上有插座、东西没摆正 |
| 具体光源 | 6 | 只有窗光一侧亮、顶灯偏白脸上光很平、台灯暖光混冷光、傍晚橙光…… |
| 手机前置姿势 | 7 | 广角近距、仰角、手持入镜、镜面反光、单眼失焦…… |

每张随机组合，再追加两条硬约束：

- **「背景清晰可辨，不要人像模式虚化」** —— 手机前置传感器小、又是广角，景深很大，背景本来就不会糊。AI 经常强塞人像虚化，这是「一眼假」的最大来源之一。
- 「真实手机随手拍，不是样片也不是摆拍，非精修、非 AI 绘图」

**随机是关键。** 固定用同一组描述，几张图会像同一个模板套出来的，反而更假。

### 皮肤瑕疵是可选的，默认关闭

另有一组「皮肤与服饰瑕疵」池（毛孔、碎发、黑眼圈、衣领皱、噪点、镜头雾），由**独立配置项「皮肤与服饰瑕疵」**控制，**默认 0（关闭）**。

因为脸通常本身已经画得够好，加这些反而会把脸画脏。只有当你觉得「人太干净了不像真人」时，才调到 1-2。

### 如果还是假，先查这三项

1. **尺寸**：方图（`1024*1024`）本身就"不像手机拍的"。改成 `1024*1536` 竖图，比例对了立刻真一截。
2. **风格补充词**：填了「日系胶片感」「高级感」「电影感」之类就删掉，这些词在往 AI 味上推。
3. **背景环境真实感**：调到 4，同时把「皮肤与服饰瑕疵」保持在 0-1。

## 主动发图

不用你开口，她会在一天里的某个随机时刻自己拍一张发过来。

- 只在**最近 24 小时聊过天**的会话发
- **每天最多 2 张**，凌晨不打扰
- **没锁脸不会发**（脸会飘，发了也没意义）
- 发送时刻是**当天随机挑的**，不是准点，避免像定时任务
- 拍什么由她自己想：结合人设和当前时间是早上还是深夜，可能是刚起床、在便利店、在教室

### 每日配额（标记位实现）

配额记账在 `state.json` 的 `quota` 字段：

```json
{"date": "2026-10-29", "used": 2, "exhausted": true}
```

- 每成功发出一张，`used` 加一（**发送失败不扣配额**）
- 达到 `daily_limit`（默认 2）时，`exhausted` 置 `true`
- `exhausted` 为 `true` 时，`_tick` 在**最前面直接 return**——连抓取和生成都不会触发，不是发出去再拦
- 日期跨天后自动重置 `used = 0`、`exhausted = false`

所以「用尽后当天彻底禁止」是硬保证，不依赖每次重新计算计数。

用户主动要图（`/自拍` 或让 AI 拍）**不受这个配额限制**，随时可以。

```
/主动图关      不想被主动打扰
/主动图开      重新打开
/主动图状态    看今天发了几张、下次大概什么时候
```

## 一致性是怎么保证的

两层保险：

1. **参考图**：锁定的那张图作为 `image` 塞进请求的 `content`，模型按身份锚点保持五官；
2. **文字锚定**：`character_face` 这段描述出现在每一条自拍提示词里，并额外追加「五官和脸型必须与参考图中的是同一个人」。

任何一层单独用都能出图，两层一起才稳。

## 已知限制

- **Token Plan 不支持本地文件上传**。官方文档明确要求参考图用公网可访问的 https URL。本插件尝试用 `data:image/png;base64,...` 内联传递（DashScope 多模态接口支持这种形式），如果服务端拒绝，会自动降级为纯文字描述出图——**此时脸的一致性会明显下降**。日志里会出现「参考图模式失败，降级为纯文本」。
- 生图是**同步接口，单次只出一张**，4 张候选是并发发起 4 次请求，不是一次请求 4 张。
- 图片 URL 24 小时过期，插件会立刻下载到本地再发送。
- 图片内容会经过百炼的内容安全审核，被拒时返回 `DataInspectionFailed`。
