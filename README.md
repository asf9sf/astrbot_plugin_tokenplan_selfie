# TokenPlan 角色自拍插件（AstrBot）

让 AI 以自己的人格身份拍照——自拍、风景、随手拍。核心是**锁脸**：认定一张脸之后，换衣服换场景都还是同一个人。

## 长相从哪来：人设 → 外貌提示词

角色长什么样不是写死的，而是**由当前人格设定推理出来的**：

```
用户在人格里写好人设（发色、年龄、气质…）
        ↓
第一次 /自拍 时，插件把人格文本交给大模型
        ↓
大模型输出一段 40-80 字的纯外貌描述（只写长相，不写性格/衣服/场景）
        ↓
存进 face/appearance.txt，之后每张图都复用它
```

这样做的好处是：换人格就换长相，不用手动改提示词；而且**只总结一次**，后面所有图共用同一段描述，不会因为每次重新描述而漂移。

- `/外貌` —— 看看当前这段描述长什么样
- `/外貌重写` —— 丢掉旧的，按当前人设重新总结一份

> 首次发 `/自拍` 时如果插件还没读过人格（比如刚启动、还没聊过天），会提示你「先随便聊一句」。因为人格文本是每轮对话时顺带缓存下来的，纯命令不会触发。

## 锁脸流程（重要）

有三种定脸方式，**推荐直接用你手上的图**，比抽卡靠谱得多：

**方式一：直接对 AI 说话（最省事）**

```
[发一张图] 就用这张脸
[发一张图] 记住我长这样
[发一张图] 以后都按这张
```

AI 会自己判断这是确认意图，调用 `lock_face` 把图锁成角色的脸。**需要先在人格里勾选 `lock_face` 工具。**

用户只是发图聊天、让你评价照片时，AI 不会误锁。

**方式二：命令**

```
[发一张图] + /定脸
```

插件直接抓取这条消息里的图片存成角色的脸。

**方式三：从生成的候选里挑**

```
/自拍           → 生成 4 张候选，按顺序编号 1~4
/定脸 2         → 把第 2 张锁成角色的脸
```

**辅助命令**

```
/定脸状态       → 查看当前锁定信息
/定脸重置       → 解除锁定，重新挑
```

锁定后的图片和元数据存在插件数据目录：

```
data/plugin_data/astrbot_plugin_tokenplan_selfie/face/
├── locked.png       # 锁定的参考图
├── face.json        # 锁定时间、外貌描述、来源
└── appearance.txt   # 由人设总结出的外貌描述（所有自拍共用）
```

## 让 AI 自己拍

开启 `enable_tool` 后，需要在**人格管理 → 工具**里勾选两个工具：

- `take_selfie(scene, outfit, mood)` —— 自拍，画面里有角色本人
- `take_photo(scene)` —— 风景/环境照，画面里没有人

勾选后，用户说「你在干嘛」「发张自拍」「你那边天气怎么样」之类的，AI 会自己决定拍一张。

## 模型怎么选（省钱）

百炼华北2（北京）公开按量价：

| 模型 | 价格 | 定位 |
| --- | --- | --- |
| `wan2.7-image` | **0.20 元/张** | 标准版，最便宜 |
| `wan2.7-image-pro` | 0.50 元/张 | 旗舰版，主体一致性、文字渲染更强 |
| `qwen-image-3.0-pro` | Pro 档，约 0.5 元/张 | 人物身份保持强，1~3 张参考图 |

**三者里 `wan2.7-image` 最便宜，另外两个大约是它的 2.5 倍。**

关键点：`wan2.7-image` 本身**也支持参考图**（`image` 字段可传 1 张或多张，URL 或 base64），所以锁脸不一定非要上贵模型。本插件默认两个都填 `wan2.7-image`：

- **没锁脸 / 拍风景 / 锁脸自拍** → 全部 `wan2.7-image`，0.2 元/张
- 如果实测发现换场景后脸漂移明显 → 把「带参考图模型」单独改成 `wan2.7-image-pro`，只让锁脸的自拍走贵模型

一次 `/自拍` 出 4 张候选 = 0.8 元。锁定后每张 0.2 元，改 pro 则 0.5 元。

## 配置

| 面板名称 | 默认 | 说明 |
| --- | --- | --- |
| Token Plan 套餐 API Key | — | `sk-sp-` 开头，和语音插件可共用 |
| 普通出图模型 | `wan2.7-image` | 便宜的那个 |
| 带参考图模型 | `qwen-image-3.0-pro` | 锁脸用 |
| 出图尺寸 | `1024*1024` | 自拍建议 `1024*1536` 竖图 |
| 由人设自动生成外貌描述 | 开 | 首次 `/自拍` 时让人格模型总结长相；关掉则用下面的固定描述 |
| 外貌总结的补充要求 | 空 | 追加给模型的指示，如「银发」「偏写实摄影」 |
| 固定外貌描述（兜底） | 一段默认女性描述 | 自动总结关闭或失败时使用，**越具体越稳** |
| 统一风格补充词 | 空 | 如「日系胶片感」「午后暖色调」 |
| 每次候选张数 | 4 | 每张独立计费 |
| 同一会话冷却秒数 | 10 | 防止刷屏烧额度 |

## 一致性是怎么保证的

两层保险：

1. **参考图**：锁定的那张图作为 `image` 塞进请求的 `content`，模型按身份锚点保持五官；
2. **文字锚定**：`character_face` 这段描述出现在每一条自拍提示词里，并额外追加「五官和脸型必须与参考图中的是同一个人」。

任何一层单独用都能出图，两层一起才稳。

## 已知限制

- **Token Plan 不支持本地文件上传**。官方文档明确要求参考图用公网可访问的 https URL。本插件尝试用 `data:image/png;base64,...` 内联传递（DashScope 多模态接口支持这种形式），如果服务端拒绝，会自动降级为纯文字描述出图——**此时脸的一致性会明显下降**。日志里会出现「参考图模式失败，降级为纯文本」。
- 生图是**同步接口，单次只出一张**，4 张候选是并发发起 4 次请求，不是一次请求 4 张。
- 图片 URL 24 小时过期，插件会立刻下载到本地再发送。
- 图片内容会经过百炼的内容安全审核，被拒时返回 `DataInspectionFailed`。
